# RA-PocketSound
O PocketSound é uma aplicação web destinada a ouvintes musicais que simula o
funcionamento de um aparelho portátil de música com cartões de memória virtuais. O
sistema permitirá que o usuário crie, organize e utilize cartões digitais para armazenar
arquivos de áudio em formato MP3. Cada cartão terá capacidade para armazenar até
50 músicas, e o usuário poderá criar quantos cartões desejar. Para utilizar os cartões,
haverá cinco slots disponíveis para importação simultânea. Não haverá sistema de
login, os cartões serão exportados e importados pelo próprio usuário. Enquanto o site
estiver aberto, as músicas poderão ser utilizadas normalmente, caso o usuário feche a
aplicação sem exportar o cartão, os dados poderão ser perdidos. Ao criar um cartão, o
usuário poderá definir seu nome e sua descrição. Depois, poderá adicionar arquivos de
áudio e cadastrar informações como título, artista e gênero. O sistema permitirá ligar e
desligar os cartões, sem limitar a quantidade de cartões que podem permanecer
ligados. Quando um cartão estiver ligado, suas músicas serão exibidas no catálogo e
poderão ser reproduzidas pelo navegador. Ao desligá-lo, suas músicas deixarão de
aparecer no catálogo principal, mas continuarão disponíveis enquanto o cartão estiver
carregado. O usuário também poderá editar, excluir, exportar e importar cartões, além
de editar ou excluir músicas. Cada música poderá receber uma avaliação com uma nota
de 1 a 5 estrelas e um breve comentário sobre a opinião do usuário
