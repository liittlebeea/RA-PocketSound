# RA-PocketSound
O PocketSound é uma aplicação web destinada a ouvintes musicais que simula o
funcionamento de um aparelho portátil de música com cartões de memória virtuais. O
sistema permitirá que o usuário crie, organize e utilize cartões digitais para armazenar
arquivos de áudio em formato MP3 que serão dispostos em um grande catálogo.

## Classes de cadastro
O PocketSound será organizado em três cadastros: Cartão de Memória, Música e
Avaliação. Os cartões poderão ser criados, editados, excluídos, importados e
exportados, com capacidade para até 50 músicas cada. As músicas serão vinculadas
aos seus respectivos cartões e poderão ser adicionadas, editadas, excluídas, listadas e
reproduzidas. Já as avaliações permitirão registrar uma nota de 1 a 5 estrelas e um
breve comentário sobre cada música. Todos os cadastros terão as operações de incluir,
alterar, excluir e listar.

## Tecnologias
JSP, Gson, JSON e o servidor usado (Tomcat).
